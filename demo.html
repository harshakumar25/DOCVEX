1. Transformer Architecture — Scaled Dot-Product Attention

An attention function can be described as mapping a query and a set of key-value pairs to an output, where the query, keys, values, and output are all vectors. The output is computed as a weighted sum of the values, where the weight assigned to each value is computed by a compatibility function of the query with the corresponding key. We compute the matrix of outputs as Softmax of (Q multiplied by K transpose divided by the square root of d_k) multiplied by V.

2. Node.js Architecture — The Event Loop & Microtasks

The Node.js event loop operates across distinct phases: timers, pending callbacks, idle/prepare, poll, check, and close callbacks. Crucially, the microtask queue—which processes Promise resolutions and process.nextTick callbacks—runs to exhaustion immediately after the currently running operation completes, regardless of the current event loop phase, which can cause event loop starvation if recursive microtasks are scheduled.

3. Distributed Systems — RAFT Leader Election

Raft achieves consensus through a strong leader paradigm. Servers begin as followers; if election timeouts expire without receiving heartbeats from a leader, a follower transitions to a candidate, increments its current term, and broadcasts RequestVote RPCs. A candidate wins the election when it receives votes from a strict majority of servers in the cluster for that term, ensuring at most one leader can be elected per term.
